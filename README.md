# Daytrack 2

Improved version of [Daytrack](https://github.com/aaron5545/daytrack).

Live: https://aaron5545.github.io/daytrack2/

- Single self-contained `index.html`, no backend. Data stays in your browser.
- Storage key `daytrack2.v1` (separate from v1's `daytrack.v1`). On first launch it copies v1's data once if present.
- To update: replace `index.html` and commit to `main`; Pages redeploys in about a minute.
